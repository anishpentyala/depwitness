# Contributing

Keep changes small enough to inspect, with tests for the stated rule, edge cases,
invalid input and the previous behavior. New formats, comparison policies or
runtime dependencies need an issue discussing the contract before a pull request.
Performance claims need reproducible inputs and correctness controls. Do not
change a false or incomplete audit into a passing report. Automated contributions
are allowed under these same requirements. Do not include private data in issues,
examples, tests or reports. Contributors are responsible for understanding their
changes and answering review questions truthfully.
